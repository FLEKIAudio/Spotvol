# Changelog

## 1.2 – 2026-11-21
- The error log now lives in `~/Library/Logs/Spotvol/spotvol.log` instead of next to the app (in Applications). It's cleared automatically once it reaches about 100 KB.
- The DMG shortcut is now called "Applications".
- Copyright is now FLEKIAudio.
- Prepared for GitHub: README with screenshots, MIT license, changelog, `.gitignore`.

## 1.1
- New name: Spotvol. New app icon (a volume dial).
- The mute key (F10) mutes Spotify and restores the previous volume.
- Copyright line in the menu.
- Menu bar: icon, mini bar and percentage in one thin outline. Volume slider in the menu. Custom key bindings.

## 1.0
- First version: F11/F12 change the Spotify volume in 5 % steps while Spotify is open.
